# Stage: page — 页面设计

## 目的

只设计目标页面或页面族，明确层级、布局、状态、响应式变换和关键交互。

## 顺序

```text
用户任务
→ 信息层级
→ 页面区域
→ 主路径
→ 状态
→ 响应式转换
→ 视觉表达
```

## 高密度页面

优先形成：

```text
Context → Signal → Explanation → Exception → Action
```

而不是机械堆叠 Card。

## 产出

- `<page-id>.page.yaml`
- 页面 Design Notes
- 关键交互与状态说明

## 限制

不得借页面设计修改产品级 IA，除非 Scope 明确包含。
