# Stage: design-system — 设计系统

## 目的

建立可复用的 Design Tokens、Theme、Component Contracts 与 Density / Motion 规则。

## 输入

- 已批准的 Design Direction
- 品牌约束
- 目标页面
- 当前技术 Profile（如有）

## 必须定义

```text
Color
Typography
Spacing
Radius
Elevation
Density
Motion
States
Responsive
Accessibility
```

## 原则

Design Tokens 是产品视觉权威；UI Library、Tailwind 或其他框架只是实现层。

## 产出

- Tokens
- Component Contracts
- Theme Strategy
- Design System Brief

## 限制

没有明确 Scope 时，不修改业务页面与业务逻辑。
