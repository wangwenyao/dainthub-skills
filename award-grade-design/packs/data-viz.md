# Pack: data-viz

数据可视化优先服务比较、趋势、异常和决策。

## 先问要回答什么

```text
比较大小      → 条形图（水平方向更好排标签）
看趋势        → 折线图
看构成        → 堆叠条 / 面积；只有份额长期稳定时才用饼图
看分布        → 直方图 / 箱线图 / 散点图
看相关        → 散点图
看偏差        → 差异条 / 双向条
看单值状态    → 指标卡，不要为只有一个数的结论画图
```

不要为了填满布局而画图。一个说不出它回答什么问题的图应该删掉。

## 编码规则

- 位置与长度比面积、角度、颜色深浅更容易被准确读取；重要的量用位置编码。
- 数值轴默认从 0 开始；需要截断时必须显式标注。
- 颜色用于分组和状态，不用于装饰；同一含义在同页面用同一颜色。
- 序列色只表达有序量，不要把分类色当连续色用。
- 直接标注优先于图例——读者不该在图形和图例之间来回跳。

## 必须定义的图状态

```text
empty / loading / partial / error / permission-denied
```

以及：

- 数据点极多时的降采样或聚合策略。
- 时间轴跨时区、跨粒度（日 → 周 → 月）时的处理。
- 数值缺失与数值为零的区别。

## 不做的事

- 不用装饰性图表填充页面。
- 不为“高级感”牺牲读数与比较效率（3D、阴影、渐变填充）。
- 不用颜色作为唯一的状态区分手段。
