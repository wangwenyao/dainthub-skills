# Pack: product-context

当产品并非典型高密度业务系统时加载，用来补齐“为谁、为什么”。

## 需要回答的问题

```text
用户角色      有哪几类人，各自的目标和约束是什么
核心任务      他们来这里要完成的那一件最主要的事
内容结构      有哪些对象，彼此是什么关系
品牌语气      应该让人感觉专业 / 亲和 / 权威 / 克制
产品差异化    与同类产品相比，用户为什么选它
成功判据      什么情况算用得好
```

## 用法

- 这些答案要能直接约束设计决策。如果一条“品牌语气”推不出任何 Do / Don't，
  说明写得还不够具体。
- 角色超过三个时，先确定哪一个是主要服务对象，不要同时为所有人优化。
- 核心任务只能有一个主答案；出现并列，说明还没想清楚。

## 何时可以跳过

- 已有明确 PRD 或 Design Direction 时，直接引用，不要重新推导。
- 产品属于 BI / ERP / CRM / CDP / MA / 数据平台等高密度场景时，优先加载
  `packs/high-density.md`；本 Pack 只在需要补充品牌与用户语境时读。
