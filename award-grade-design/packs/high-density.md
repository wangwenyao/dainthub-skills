# Pack: high-density

适用于 BI、Dashboard、ERP、CRM、CDP、MA、运营平台、数据平台、科研软件等。

核心公式：

```text
单位视口信息价值
+ 扫描效率
+ 层级
+ 分组
+ 决策有效性
```

不要把密度理解为缩小一切。应使用：

```text
comfortable / standard / compact
```

Dashboard 推荐：

```text
Context → Signal → Explanation → Exception → Action
```

Table / Filter / Toolbar 必须定义优先级、密度、溢出、状态和恢复路径。
