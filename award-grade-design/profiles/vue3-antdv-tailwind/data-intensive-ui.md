# Data-Intensive UI

## Dashboard

优先：

```text
Context
→ Signal
→ Comparison
→ Explanation
→ Exception
→ Action
```

## Table

必须定义：

```text
column priority
row density
sorting / filtering
selection
overflow
sticky region（如确有必要）
loading / empty / error
responsive transformation
```

## Chart

图表必须服务比较、趋势、异常或决策，不作为纯装饰。

## Toolbar

控制项按任务优先级分组，不要把所有 Filter 平铺成同等权重。
