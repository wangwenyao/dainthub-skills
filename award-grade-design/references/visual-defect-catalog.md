# Visual Defect Catalog

## P0

- 主任务无法完成
- 严重视觉遮挡导致功能不可用
- 关键交互或状态错误
- 严重 Accessibility 问题

## P1

- 信息层级明显错误
- 关键操作难找
- 高密度页面无法快速扫描
- Responsive 导致主要任务失真
- 组件状态缺失导致用户误判

## P2

- 对齐不一致
- Typography 比例失衡
- Token 使用不一致
- Card / Border / Shadow 过度
- Icon 或状态表现不统一

## P3

- 微小间距
- 非关键 Motion
- 可选的品牌细节

优先修复 P0/P1，不得用 P3 装饰掩盖结构问题。
