# Visual Defect Catalog

## P0

- 主任务无法完成
- 严重视觉遮挡导致功能不可用
- 关键交互或状态错误
- 严重 Accessibility 问题

## P1

- 信息层级明显错误
- 关键操作难找
- 高密度页面无法快速扫描
- Responsive 导致主要任务失真
- 组件状态缺失导致用户误判

## P2

- 对齐不一致
- Typography 比例失衡
- Token 使用不一致
- Card / Border / Shadow 过度
- Icon 或状态表现不统一

## P3

- 微小间距
- 非关键 Motion
- 可选的品牌细节

## 渠道可验证性

盲查模式（自动化可用、视觉通道不可用）下各级条目的可判定性：

- 文本渠道可判定，照常执行并标「已验证（文本渠道）」：P0 全部四项；信息层级明显错误
  （标题层级与 computed 字号阶梯代理）、关键操作难找（可达性与 CTA 尺寸 / 对比度代理）、
  Responsive 导致主要任务失真、组件状态缺失导致用户误判、对齐不一致、Typography 比例
  失衡、Token 使用不一致、Icon 或状态表现不统一、微小间距、Motion 的存在性与
  reduced-motion 支持。
- 无文本代理，标「未验证（需视觉通道）」并移交人工复核：高密度页面无法快速扫描、
  Card / Border / Shadow 过度、可选的品牌细节、非关键 Motion 的感知质量。

未验证模式（自动化不可用、无本地渲染证据）→ 全部视觉项标「未验证」，按用户提供
材料或人工目检补充证据。

具体取证方法见 `references/visual-qa-protocol.md` 的「盲查取证通道」，本表只声明
可判定性，不重复做法。

优先修复 P0/P1，不得用 P3 装饰掩盖结构问题。
