# Acceptance Criteria

## UX

- 目标任务可完成。
- 关键路径明确。
- 主要信息可快速扫描。

## Visual

- Design Direction 得到一致执行。
- Token 使用一致。
- 组件和页面具有稳定的视觉层级。

## Interaction

- 状态完整。
- Focus / Keyboard 清晰。
- Error / Empty / Loading 有合理恢复路径。

## Responsive

- 页面在目标 viewport 保持任务可理解性。
- 不依赖简单缩放维持布局。

## Engineering

- Typecheck / Lint / Test / Build 在可用时通过。
- 无明显 console error / warning。

## QA

- 无未解决 P0。
- 关键 P1 已处理或明确接受。
- 达到当前 Stage 的质量门槛。
